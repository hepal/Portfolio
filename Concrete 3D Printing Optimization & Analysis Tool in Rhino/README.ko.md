# Rhino 콘크리트 3D 프린팅 최적화 및 분석 도구

불규칙한 형상의 콘크리트 매스에 대한 3D 프린팅 적합성을 분석하고 최적화하여, 실제로 한 층도 출력하기 전에 구조적 타당성을 검증하는 Rhino 7용 커스텀 Grasshopper 플러그인 스위트입니다.

## 개요

대학 건축 연구 프로젝트로 의뢰받아 개발한 이 10종 이상의 C# .NET Grasshopper 모듈 스위트는, 프리폼 건축 형태의 콘크리트 3D 프린팅에 필요한 복잡한 내부 채움 지오메트리 생성을 자동화합니다. 멀티코어로 병렬 처리되는 최적화된 지그재그 툴패스를 생성하고, 이를 3D 메쉬 형태의 "프린트 비드" 리본으로 변환한 뒤, 그 결과를 프린트 품질 문제 관점에서 분석합니다 — 이를 통해 연구자들은 구조적·재료적 문제를 프린터가 아닌 소프트웨어 단계에서 사전에 발견할 수 있습니다.

**비즈니스 가치:** 복잡한 프린팅 가능 지오메트리에 대한 반복 작업 속도 향상, 재료 낭비 및 프린팅 실패 감소, 제작 이전 단계에서의 정량적·색상 코드화된 프린트 품질 검증.

## 주요 기능 및 문제 해결

- **커스텀 Grasshopper 플러그인 스위트** — 콘크리트 적층 제조 워크플로를 위해 Rhino 7 / Grasshopper를 확장하는, 10종 이상의 목적 특화 C# .NET 모듈.
- **채움 지오메트리 자동 생성** — 불규칙하고 비정형적인 건축 매스에 대해 산출된 면적 오프셋을 계산하고 내부 채움 지오메트리를 생성합니다.
- **멀티코어 최적화 툴패스 라우팅** — 효율적이고 프린팅 준비가 완료된 경로 생성을 위해 병렬화(`Parallel.For`)된 지그재그 라우팅 알고리즘을 구현합니다.
- **3D 프린트 비드 시뮬레이션** — 라우팅된 경로를 물리적으로 압출되는 프린트 비드를 정확히 표현하는 3D 메쉬 리본으로 변환합니다.
- **오버필/언더필 분석** — 고급 분석기가 색상 코드화된 맵을 통해 오버필·언더필 구역을 시각화하며, 레이어별 미지지/브리지/캔틸레버/정상 구간에 대한 정량적 리포트를 제공합니다.
- **구조적 타당성 검증** — 실제 프린팅 전에 프린트 품질 및 지지 관련 문제를 드러내어 재료 낭비와 프린팅 실패를 줄입니다.
