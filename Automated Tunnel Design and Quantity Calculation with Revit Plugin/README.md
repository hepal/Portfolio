# Automated Tunnel Design and Quantity Calculation with Revit Plugin

A custom Autodesk Revit plugin that automatically generates tunnel geometry and quantity take-off tables from simple numerical inputs, replacing manual tunnel modeling with a fast, parametric, GUI-driven workflow.

## Overview

Civil/infrastructure teams typically spend significant time manually modeling tunnel cross-sections and geometry, then separately calculating material quantities. This plugin closes that gap: users enter numerical values and attributes through a custom GUI, and the tool automatically constructs the corresponding tunnel geometry inside Revit and produces a complete quantity table — in one continuous, repeatable process.

**Business value:** dramatically faster tunnel design iteration, elimination of manual modeling and quantity-takeoff errors, and consistent, standardized outputs for estimation and design review.

## Key Features & Problem Solving

- **Parametric GUI Input** — users define tunnel attributes and numerical values through a purpose-built interface, with no manual CAD modeling required.
- **Automated Geometry Generation** — the plugin programmatically constructs accurate tunnel geometry inside Revit from the supplied parameters.
- **Automatic Quantity Table Generation** — produces a complete materials/quantity take-off table alongside the generated geometry, ready for estimation.
- **Faster Design Iteration** — changing input parameters regenerates geometry and quantities instantly, enabling rapid design comparison.
- **Error Reduction** — removes manual measurement and calculation steps that are prone to human error in traditional tunnel quantity surveys.
