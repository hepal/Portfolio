# Unity 기반 산업단지 대기질 및 오염물질 모니터링 3D 대시보드

산업단지 전체를 인터랙티브 3D 도시 모델로 렌더링하고, 현장 센서와 CCTV 영상을 지도 위에 함께 표시하여 산업단지의 대기질과 오염물질 배출을 모니터링하는 Unity 기반 3D 대시보드입니다. 넓은 지역 렌더링과 LOD 처리를 통해 일반 Windows PC에서도 빠르고 메모리 효율적으로 동작합니다.

## 개요

산업단지는 공장, 도로, 주거 인접 지역이 밀집한 넓은 지역이며, 대기질 및 오염 센서가 곳곳에 흩어져 있습니다. 이 데이터를 표나 2D 지도로만 보면 문제가 *어디에서* 발생했는지, 주변에 무엇이 있는지 파악하기 어렵습니다. 이 프로젝트는 산업단지 전체를 하나의 3D 화면에 담습니다.

1. **3D 산업단지 모델** — 산업단지와 주변 지역의 항공 영상과 3D 건물 모델을 지도처럼 탐색할 수 있습니다.
2. **센서 및 CCTV 오버레이** — 모니터링 지점(대기질, 기상, 교통, 공장 센서)을 실제 위치에 아이콘으로 표시하고, 검색 가능한 센서 목록과 주요 교차로·입구의 실시간 CCTV 화면을 제공합니다.
3. **넓은 지역 성능 최적화** — 넓은 지역 렌더링과 LOD(Level of Detail) 처리로 산업단지 전체를 표시하면서도 반응 속도를 유지하고 메모리 사용량을 줄였습니다.

**비즈니스 가치:** 운영자는 산업단지 전역의 대기질과 오염원을 하나의 3D 화면에서 모니터링할 수 있으며, 여러 시스템을 오가지 않고도 센서나 이상 상황의 위치를 실제 주변 환경과 함께 빠르게 파악할 수 있습니다.

## 주요 기능

- **3D 산업단지 지도** — 항공 영상과 3D 건물 모델로 구성된 산업단지 지도와 홈·확대/축소·시점 제어 기능을 제공합니다.
- **센서 현황 패널** — 모니터링 지점(입구, 교차로, 공장)을 검색할 수 있는 목록을 제공하며, 센서를 선택하면 3D 화면에서 해당 위치로 이동합니다.
- **지도 센서 아이콘** — 대기질, 기상, 교통 모니터링 지점을 실제 위치에 아이콘으로 표시합니다.
- **CCTV 모니터링** — 교차로와 산업단지 입구의 CCTV 영상을 멀티 뷰 패널로 보여줍니다.
- **측정 도구** — 지도 위에서 직접 거리를 측정하고 구간별 길이와 총 거리를 표시합니다.
- **넓은 지역 렌더링 및 LOD** — 넓은 산업단지 영역에 LOD 처리를 적용하여 렌더링 속도를 높이고 메모리 사용량을 줄였습니다.
- **다중 사이트 적용** — 여러 산업단지(부산, 포항 등)에 적용되었습니다.

## 기술 스택

- C#
- Unity3D
- Windows 10 / Windows 11
