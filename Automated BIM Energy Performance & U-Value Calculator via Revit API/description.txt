Project description *
This project is a custom Revit add-in designed to automate the extraction and analysis of building energy performance data. Leveraging the Revit API, the tool extracts real-time BIM data to identify and analyze the materials of exterior walls, openings, and floors. It systematically calculates the thermal conductivity of composite materials and automatically generates comprehensive energy performance certificates and thermal transmittance (U-value) reports. This automation significantly reduces manual data entry and ensures highly accurate environmental data analysis for building projects.
