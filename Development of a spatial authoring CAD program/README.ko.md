# 공간 데이터 저작용 CAD 프로그램 개발

복잡한 CAD 환경과 최종 사용자 사이의 간극을 메우는, 처음부터 새로 구축한 전문 공간 데이터 저작 툴입니다. 전문적인 3D 모델링 기술이 없는 비전문가도 관제·모니터링 시스템에 바로 활용 가능한 3D 공간 데이터를 제작할 수 있게 해줍니다.

## 개요

시설 및 건물 운영자는 모니터링 대시보드와 디지털 트윈을 구동하기 위해 정확한 3D 공간 데이터가 필요하지만, 이를 제작하려면 전통적으로 전담 CAD/BIM 전문 인력이 필요했습니다. 이 프로젝트는 엔진과 UI를 모두 자체 개발한 완전한 데스크톱 CAD 저작 애플리케이션을 제공하여, 최종 사용자가 3D 공간 환경을 직접 그리고, 구조화하고, 내보낼 수 있게 합니다. 이렇게 만들어진 데이터는 이후 3D 관제·모니터링 시스템으로 전달됩니다.

**비즈니스 가치:** 시설 데이터 저작을 위한 전문 3D 모델러 의존도 제거, 평면도에서 실시간 모니터링 대시보드까지 이어지는 경로 단축, 후속 시스템을 위한 공간 데이터 산출물의 표준화.

## 주요 기능 및 문제 해결

- **처음부터 구축한 풀스택 CAD 엔진** — 서드파티 CAD SDK에 의존하지 않고, 2D 평면도 저작과 3D 시각화를 모두 아우르는 자체 렌더링/편집 엔진과 UI.
- **비전문가를 위한 공간 저작** — 벽체, 기둥, 문, 창, 곡선 벽 등의 전용 드로잉 도구와 POI, 셀 노드, 오토 노드, 요소 할당 등의 토폴로지 도구를 통해 CAD 비전문가도 구조화된 공간 데이터를 제작할 수 있습니다.
- **자산/장비 라이브러리 시스템** — 랙, 레일 등 파라메트릭 장비를 드래그 앤 드롭으로 배치하는 라이브러리와, 프로젝트 간 재사용을 위한 커스텀 라이브러리 항목의 저장/가져오기/내보내기 기능.
- **2D-3D 공간 토폴로지 생성** — 저작된 2D 평면도로부터 3D 셀-공간 토폴로지와 노드 네트워크 연결 관계를 자동으로 도출합니다.
- **제작 즉시 사용 가능한 데이터 내보내기** — 후속 3D 관제·모니터링 시스템에서 바로 활용 가능한 형태로 공간 데이터를 출력하여, 저작부터 실시간 대시보드까지 이어지는 흐름을 완결합니다.
- **엔드투엔드 검증** — 동일하게 저작된 공간 모델이 실별 실시간 환경 데이터를 보여주는 웹 기반 실시간 모니터링 대시보드를 구동함으로써, 데이터 파이프라인이 전 과정에서 정상 동작함을 입증합니다.
