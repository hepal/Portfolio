# 구강 3D 스캔 마진 라인 검출 및 치아 레이블링 도구

주곡률 분석으로 구강 3D 스캔 메쉬에서 치아와 잇몸의 경계(마진 라인)를 자동 검출하고, 작업자가 몇 번의 클릭만으로 치아마다 FDI 번호를 부여할 수 있는 커스텀 Unity 에디터 도구를 함께 제공하는 치과 스캔 데이터 처리 파이프라인입니다.

## 개요

크라운 설계나 치아별 분리 같은 치과 CAD 후속 작업을 위해 구강 스캔을 준비하려면, 약 10만 개 정점으로 이루어진 조밀한 메쉬 위에서 마진 라인을 수작업으로 따고 치아를 분리해야 합니다. 이 과정은 느리고 번거로우며 작업자마다 결과가 달라집니다. 이 프로젝트는 문제를 두 단계로 나누어 해결합니다.

1. **Python 파이프라인** — STL 스캔을 점 데이터로 변환하고 정점별 오목 곡률을 계산한 뒤, 교합면과 고립 노이즈를 걸러내 마진 라인과 인접면 엣지만 남깁니다. 결과는 Unity에서 바로 쓸 수 있는 포맷(PLY, GLB, JSON, CSV)으로 내보냅니다.
2. **Unity 레이블링 도구** — 곡률 데이터를 히트맵으로 불러와 자연스러운 "장벽"으로 활용합니다. 치아를 클릭하면 BFS 플러드 필이 마진 라인에서 멈추면서 치아 전체에 FDI 레이블을 한 번에 부여합니다. 레이블은 다음 단계(치아별 메쉬 분리)의 입력으로 내보냅니다.

**비즈니스 가치:** 전악(Full-arch) 스캔의 마진 라인 후보를 약 0.5초 만에 계산하고, 치아 레이블링을 수작업 정점 선택에서 치아당 클릭 한 번으로 바꾸어 후속 자동화에 쓸 수 있는 일관된 레이블 데이터를 확보합니다.

## 주요 기능 및 문제 해결

- **곡률 기반 마진 라인 검출** — 정점별 k-NN 공분산 고유값 분해(Surface Variation)와 오목/볼록 판별을 완전 벡터화하여 약 94K 정점을 약 0.5초에 처리합니다.
- **다단계 노이즈 필터링** — Z 높이 *와* 상향 법선을 함께 만족하는 조건으로 교합면(씹는 면)을 억제하고, 상위 10% 강한 엣지만 남긴 뒤 KDTree 밀도 검사로 고립 노이즈를 제거합니다. 교합면 판별을 AND 조건으로 바꾸어, 이전 버전에서 잘못 제거되던 인접면 엣지 정점 1,117개를 복원했습니다.
- **Unity 내보내기 파이프라인** — jet 컬러맵 정점 색상을 포함한 PLY/GLB/JSON/CSV 출력과, 선택적인 Z-up → Unity Y-up 좌표계 변환을 지원합니다.
- **플러드 필 치아 레이블링** — 치아를 클릭하면 곡률 장벽까지 영역을 채웁니다. 임계값과 최대 채움 반경을 조절할 수 있고, 세대(generation) 카운터 방식의 방문 배열로 매 채움마다 O(1)로 초기화합니다.
- **수동 배리어 페인팅** — 곡률만으로 인접 치아를 구분하기 어려운 좁은 접촉면에 붉은 경계선을 브러시로 그려 넣을 수 있습니다.
- **작업자 친화적 에디터** — FDI 색상표와 3D 번호 오버레이, 곡률 통계(P50/P90 임계값 빠른 설정), 델타 기반 Undo/Redo(50단계), 세션 저장/불러오기, JSON/CSV 레이블 내보내기를 제공합니다.

## 기술 스택

- Python (NumPy, SciPy, trimesh, PyVista, Matplotlib)
- Unity 6 (C#, Editor Window, URP 커스텀 셰이더)
- 3D 지오메트리 처리 (곡률 분석, KDTree, 메쉬 인접 리스트 / BFS)
